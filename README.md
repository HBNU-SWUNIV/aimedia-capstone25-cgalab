## <u>Teamate</u> Project Background
- ### 필요성
  - 실제 화재 상황에서 사람들은 공포감이나 시야제한 등으로 인해 대피 판단이 어려워짐
  - 전통적인 피난 교육과 실제 상황의 차이가 크고, 체험형 교육의 몰입감과 현실감이 부족하여 실제 대응 능력 향상에 한계가 있음
- ### 기존 해결책의 문제점
  - 영상이나 매뉴얼 중심의 교육은 실제 상황에서 학습자가 바로 행동 유도하기 어렵고 반복 학습 효과가 낮음
  - 기존 VR 시뮬레이션은 시각적 현실감이 떨어지거나 물리적 상호작용이 단순하여 몰입도가 낮음
  
## System Design
  - ### System Requirements
    - Unreal Engine 5 기반의 고품질 그래픽 및 물리 효과 구현 (연기, 불꽃, 조명 반사 등)
    - 사용자 시점에서의 자연스러운 이동 및 상호작용이 가능한 VR 시스템 구축
    - 실제 건물 구조 기반의 맵 설계 및 그래프 기반 경로 탐색 알고리즘 적용
    - 동적 환경 변화(문 차단, 연기 확산 등)에 따라 대피 경로를 실시간 갱신
      
## Case Study
  - ### Description
본 프로젝트는 Unreal Engine 5를 활용하여 화재 상황을 가상 환경에서 재현하고, 사용자가 HMD를 착용한 상태에서 몰입형 대피 훈련을 수행하도록 설계되었다.
시스템은 Ray-traced Lighting을 적용해 연기와 불꽃의 사실적인 반사 및 그림자를 구현했으며, Graph-based Pathfinding을 통해 매 상황 최소 한 개의 탈출 경로를 보장한다.
사용자는 동적 조명, 열 왜곡, 시야 흐림 효과(Vignetting 등)를 통해 실제와 유사한 긴박함을 경험하며, 행동 선택에 따라 시뮬레이션 결과가 달라진다.
  
## Conclusion
  - ### 기존 교육 방식보다 높은 몰입감과 학습 효과를 제공
  - ### 다양한 재난 상황 시나리오 확장 가능성 확보 (지진, 폭우, 지하철 화재 등)
